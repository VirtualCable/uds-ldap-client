# LDAP test servers

Integration test servers, started with Docker Compose.

## OpenLDAP

```sh
# Start, generate the test PKI (CA + server cert) and seed the test data
tests/openldap/seed.sh            # add --fresh to reset the server (down -v)

# Run the integration tests
env/bin/python -m pytest tests/integration/test_ldaputil_like.py -v   # from the repo root, with the shared venv

# Tear down
docker compose -f tests/docker-compose.yml down -v
```

* Plain LDAP: `ldap://localhost:1389`
* LDAPS: `ldaps://localhost:1636`
* Base DN: `dc=uds,dc=example,dc=org`
* Admin bind DN: `cn=admin,dc=uds,dc=example,dc=org`, password `adminpassword`
* Seed data (tests/openldap/custom/50-uds-seed.ldif): users `alice`/`bob`,
  group `staff` (member `alice`)
* Test PKI (tests/openldap/certs/, generated by gen-certs.sh, not committed):
  `ca.crt` + `ldap.crt`/`ldap.key` for CN=localhost, mounted into the
  container; the CA is used by the `verify_ssl=True` + custom-CA test

## Test layers

* `tests/integration/smoke.py` — direct native client walkthrough
  (connect, bind, search, add, modify, delete, already-exists, error kinds).
* `tests/integration/ldaputil_like.py` — minimal re-implementation of
  `uds.core.util.ldaputil` on top of the native client (same call patterns
  the UDS modules use).
* `tests/integration/test_ldaputil_like.py` — pytest suite over that layer:
  search/first/add/modify/recursive-delete/root-DSE, error mapping
  (BindError / AlreadyExistsError / LdapError), attribute fill parity and
  the TLS paths (verify off, custom CA, empty certificate → system store).

Not covered here (needs a real AD or Samba DC): AD bind sub-status messages
(data 773), `unicodePwd` handling and referral following.
